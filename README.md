# FlowDesk Studio

FlowDesk Studio 是一个完全运行在浏览器中的企业级低代码流程编排与审批监控演示平台。项目使用 React、TypeScript、Vite、Zustand 和 React Flow，所有数据均为本地 mock，不需要后端、登录或外部 API。

## 启动

需要 Node.js 20+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址（默认 `http://localhost:5173`）。建议使用 1440px 或更宽的现代桌面浏览器。

## 测试

首次运行先安装 Chromium：

```bash
npx playwright install chromium
npm test
```

Playwright 会自动启动 Vite（端口 4173），串行验证 Dashboard、编辑器审批配置、双区域校验、条件修复、动态表单预览、发布联动、异常实例详情、版本比较和历史恢复；`merge.spec.ts` 额外验证离线回连的按对象合并、字段冲突、移除待确认、结构检查闸门与预览拦截。测试失败时会保留截图和 trace。

## 浏览器验证路径

1. Dashboard 点击“差旅费用审批”进入编辑器。
2. 选择“直属主管审批”，切换审批人来源并保存草稿。
3. 运行校验，观察 Condition 节点红色错误态和底部问题面板。
4. 选择“金额判断”，配置申请金额大于 5000，再次校验。
5. 打开预览，输入金额 12000，观察模拟分支切换。
6. 返回并发布；在 Dashboard 和 Workflows 检查状态及版本。
7. 进入运行监控，筛选异常并打开实例，查看时间线及高亮节点。
8. 从编辑器进入版本历史，选择两个版本比较，再恢复旧版本为草稿。

## 离线协作与按对象合并

草稿保存不再整份覆盖。编辑器顶部“模拟离线协作”可复现两人离线编辑同一份草稿后回连的场景：

- 离线开始时定格共同基线（base），本地与协作者各自改动。
- 回连后按对象三方合并：各自新增的节点 / 连线都保留；同一对象同一字段两边都改且不一致时，进入右侧“合并待处理区”的字段冲突，必须人工选择本地或协作者版本。
- 一方移除的节点 / 连线先停在待处理区等待“确认移除 / 保留”；被其他连线引用的节点会特别标注引用提示，确认删除时相关连线一并结案。
- 合并后自动检查孤立节点、重复连线、悬空连线以及缺少开始 / 结束节点；有问题时停在待处理区，可一键“自动接入 / 自动清理 / 补起止节点”。
- 冲突未全部解决、移除项未确认或结构检查未通过时，不能接受合并，也不能保存、校验、发布或预览；合并期间画布只读。
- 发布与预览只读取通过检查的结果（预览在结构不通过时展示拦截页）。
- 只有接受后的完整草稿写入 `localStorage`，关闭浏览器后从最后完整草稿继续；未确认的冲突、待处理对象等会话内协作状态不落盘，不会被带进下一步。


## 项目结构

- `mock-data/`：12 个流程、80 个实例、8 个用户、6 个角色、5 个业务域及边界案例。
- `src/components/`：布局、公共状态组件和 React Flow 画布。
- `src/pages/`：Dashboard、流程列表、编辑器、表单预览、运行监控、版本历史。
- `src/store/`：Zustand 全局状态、校验、发布、复制、归档及恢复逻辑；`merge.ts` 为按对象三方合并，`validate.ts` 为结构检查，`persistence.ts` 负责完整草稿的本地持久化。
- `src/types/`：核心业务数据 TypeScript 类型。
- `tests/`：关键产品链路 Playwright 测试。

## Mock 边界案例

数据集中包含空流程、孤立审批节点、缺少结束节点、未配置条件分支、审批人为空、表单必填校验、超长流程名称、超长说明展示能力、无异常实例，以及由搜索筛选产生的空结果状态。
